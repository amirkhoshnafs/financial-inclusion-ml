# Analytical questions

## Main question

Which groups are financially excluded, what predicts financial inclusion, and which intervention appears most plausible to test?

## Questions

1. Which countries or groups have the lowest account ownership?
2. Which countries have the largest gender gap in account ownership?
3. Are poorer or less educated adults less likely to own accounts?
4. Is mobile phone ownership or internet access associated with account ownership?
5. Which features best predict account ownership?
6. What country clusters exist by financial inclusion profile?
7. Which policy intervention appears most plausible for excluded groups?

## Expected outputs

- country ranking table
- demographic gap charts
- model comparison table
- SHAP explanation plots
- country cluster table
- policy recommendation table
